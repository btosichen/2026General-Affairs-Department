📚 案例庫

🧭 紀錄原則

  1. 只寫可由紀錄或佐證確認的事實。
  2. 每一步都留下時間、人員、決定與結果。
  3. 緊急復原與永久改善分開追蹤。
  4. 結案前補齊圖說、照片、檢測、聯繫及驗收資料。

⚡ 臨時事件通用處理 SOP

高壓設備僅能由合格專業人員操作；現場安全與人員管制優先於復電速度。

1🚨 接報與安全隔離

記錄時間、通報人、影響範圍；封鎖危險區、禁止自行碰觸設備，必要時啟動疏散與校安通報。

2📣 啟動指揮與通知

由單一窗口統籌，通知校長、總務處、電氣負責人、維護廠商；涉及外線或送電時聯繫臺電。

3🔎 專業檢測與判斷

確認故障區段、可能原因及可否局部隔離；保存量測值、警報、照片、單線圖與專業判斷。

4🛠️ 緊急處置

由合格人員執行隔離、搶修或替代供電；記錄操作順序、使用材料、風險與核准決定。

5✅ 復電驗證

分區送電並確認電壓、負載、異音、異味及設備溫度；通知各單位確認關鍵設備恢復。

6🧾 行政與採購

補齊緊急處理依據、估價、簽辦與核銷；永久改善案確認採購屬性、規格、工期與決標方式。

7📂 結果與證據歸檔

記錄停電及復電時間、影響、處置結果、費用、廠商、照片、測試報告、會議決議及對外說明。

8🔁 改善與追蹤結案

建立永久改善任務、期限與主責；更新單線圖、設備清冊、聯絡網及本 SOP，驗收後才正式結案。

📎 每案必留資料

  • 接報、停電與復電時間
  • 影響區域與教學／行政影響
  • 現場安全管制及通報對象
  • 檢測數值、故障判斷與照片
  • 每次處置的執行人與核准人
  • 廠商聯繫、估價、工單及費用
  • 復電測試與使用單位確認
  • 後續改善案、期限及結案證據

建議使用方式

  1. 先在「任務總表」檢查內建工作，刪除不適用項目，為每項補上主責人與實際期限。
  2. 每天看總覽的紅黃燈；每週利用「主任本週檢核」開處務會議。
  3. 採購、工程或修繕案件應建立成獨立任務，並在備註留下簽辦、廠商、會議與驗收的日期紀錄。
  4. 臨時停電、災害、設備故障或重大陳情，請在「特殊事件 SOP」建立一案，依八階段流程逐步補齊事實、處置、結果與證據。
  5. 每月底按「匯出試算表 CSV」；每次重大調整前按「備份 JSON」。JSON 備份會一併保存特殊事件紀錄。

本版本將資料保存在此瀏覽器。清除瀏覽器資料前請先備份 JSON。Google 試算表即時同步需另行設定 Apps Script 授權，適合在工作流程穩定後再加入。

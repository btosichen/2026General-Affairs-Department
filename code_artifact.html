陽明高中水系進出與原理說明

陽明高中位於基河路、承德路與中正路之間，校園貫徹「雨汙分流」體系。雨水（淺藍）獨立排除入基隆河；汙水（深紅）送往迪化污水處理廠。

1. 汙水管線系統 (深紅色)

密閉地下管網

主要用途：收集陽明高中洗手間、學生餐廳/廚房、理化實驗室及體育館浴室之廢污水。

水的進出流程：
  • 流入 (In)：來自自來水系統，供教學大樓洗手台、廁所、廚房與化學/生物實驗室使用。
  • 校內預處理：餐廳污水經[SW-04] 油脂截留器；實驗室廢水經[SW-01] 酸鹼中和槽。
  • 流出 (Out)：匯集至校區深紅主幹管，經由[SW-OUT1] 基河路與[SW-OUT2] 中正路出口排入台北市地下污水幹管 ➔ 運送至迪化污水處理廠淨化。

2. 雨水管線系統 (淺藍色)

重力排水溝渠

主要用途：快速宣洩豪雨時校舍屋頂、200m 操場及中庭花園地表積水，維護校園防颱安全。

水的進出流程：
  • 流入 (In)：大氣降雨降落於校舍屋頂落水管、操場排水溝及道路雨水集水井。
  • 流出 (Out)：經校內淺藍管線與陰井 ➔ 匯入承德路五段與基河路市府雨水箱涵 ➔ 由基隆河抽水站抽排入基隆河。

臺北市立陽明高中 - 雨水與汙水管線功能、用途及水的進出完整解析

為甚麼學校需要落實「雨汙分流」？

陽明高中位於基河路、承德路與中正路交會處，緊鄰基隆河。若將雨水與污水混合排放，暴雨時會導致污水處理廠負荷過載，更會造成嚴重的水質污染與校園積水。因此，學校建置了兩套獨立不相混接的管網系統。

1. 汙水管線系統（深紅色管線）

功能與用途

專門收集全校師生生活活動所產生的廢水，包括教學大樓廁所、洗手台、廚房洗滌、體育館淋浴間及化學/生物實驗室廢水。

水的進出說明

進水：來自臺北自來水事業處供水。
出水：經過預處理後，經深紅管線匯集至基河路與中正路地下污水幹管，送往迪化/八里污水處理廠淨化處理。

總務處關鍵管制設備：
  • 學生餐廳/廚房 [SW-04]：設置「油脂截留器」，浮油殘渣需定時除油，防止油脂凝固堵塞下水道。
  • 科學館理化實驗室 [SW-01]：設置「酸鹼中和沉澱槽」，實驗廢液嚴禁直接倒入水槽，需預先中和處理。

2. 雨水管線系統（淺藍色管線）

功能與用途

收集天降雨水、地表逕流、200公尺操場及校舍屋頂積水，依靠重力迅速宣洩，防止颱風及豪雨期間校園發生淹水災情。

水的進出說明

進水：天然大氣降雨降落校區。
出水：經由雨水溝與陰井匯入承德路五段與基河路雨水箱涵，最終由基隆河抽水站抽排入基隆河。

總務處日常維護重點：

防汛期（每年5-11月）前，必須派員清理操場周邊雨水溝及校舍落水管口之落葉與泥沙，確保重力流順暢。
